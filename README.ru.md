# Window FX

[English](README.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Português](README.pt.md) · **Русский** · [日本語](README.ja.md) · [简体中文](README.zh_CN.md)

Плагин для [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell), который даёт окнам в niri собственные анимации при закрытии и открытии: они сгорают, разлетаются на осколки, тают, сбоят или гаснут, как старый кинескоп. Края светятся вашим акцентным цветом.

![Window FX](assets/screenshot.png)

Пошагово и с картинками: [руководство по установке и настройке](docs/GUIDE.ru.md).

## Что он делает

niri умеет рисовать закрывающееся или открывающееся окно собственным шейдером. Плагин записывает такой шейдер в `~/.config/niri/windowfx.kdl`, а niri сам перечитывает файл, как только тот меняется. Новая настройка действует со следующего окна, которое закрывается или открывается.

Всего 13 эффектов:

| Эффект | Что происходит |
|---|---|
| Тление | окно сгорает вдоль рваного фронта |
| Распад | крупное зерно исчезает в случайном порядке |
| Пикселизация | блоки растут, потом гаснут |
| Осколки | окно раскалывается на осколки, они вращаются и падают |
| Таяние | тонкие столбцы стекают вниз, каждый со своей скоростью |
| Сбой сигнала | разрывы, разъехавшиеся цветовые каналы и прыгающие блоки, потом окно рассыпается |
| Кинескоп гаснет | окно сжимается в линию, потом в точку, с яркой вспышкой |
| Снежная буря | картинка тонет в помехах и распадается зерно за зерном |
| Скан | луч идёт вниз и оставляет за собой каркас из контуров |
| Дождь из кода | столбцы символов бегут вниз, за ними остаётся только код |
| Водоворот | окно закручивается вокруг своего центра |
| Плитки | плитки уменьшаются в случайном порядке |
| Жалюзи | горизонтальные планки закрываются |

«Случайно» заново выбирает эффект для каждого окна из набора, который вы задаёте сами. У закрытия и открытия своя длительность. Открытие проигрывает эффект в обратную сторону: по умолчанию новое окно появляется так же, как исчезло прошлое, только наоборот. Выберите «Стандарт niri», и плагин оставит эту анимацию niri.

«Светящиеся края» зажигают края, трещины и швы акцентным цветом DMS. Когда акцент меняется, плагин записывает файл заново. «Кинескоп гаснет» всегда вспыхивает белым, с этой настройкой или без неё.

Если вы пользуетесь плагином [Profiles](https://github.com/satoshoe-dev/dms-profiles), укажите `windowFx` в разделе Настройки → Плагины → Profiles → Плагины, сохраняемые в профиле, и у каждого профиля будут свои анимации.

## Требования

DankMaterialShell 1.6.1 или новее и niri 26.04 или новее. Версия niri важна из-за строки include ниже: `optional=true` niri понимает начиная с 26.04.

Плагин пишет только свой собственный файл. niri читает его, когда ваша конфигурация niri его подключает, поэтому добавьте эту строку в конец `~/.config/niri/config.kdl`:

```kdl
include optional=true "windowfx.kdl"
```

В конец, потому что include перекрывает то, что стоит до него; так анимации плагина берут верх над анимациями из основной конфигурации.

Для «Соседи ждут» нужен ещё niri с неофициальным патчем, подробнее ниже в разделе «Соседи ждут». Всё остальное работает с обычным niri.

## Установка

Из реестра плагинов:

```sh
dms plugins install windowFx
dms ipc call plugins enable windowFx
```

Плагин также есть в каталоге DMS: Настройки → Дополнения. Установка из репозитория:

```sh
git clone https://github.com/satoshoe-dev/dms-window-fx ~/.config/DankMaterialShell/plugins/WindowFx
dms ipc call plugins enable windowFx
```

Затем выберите анимацию закрытия в Настройки → Плагины → Window FX. Пока вы этого не сделали, у niri остаются его собственные анимации.

## Настройки

Настройки → Плагины → Window FX

| Настройка | По умолчанию |
|---|---|
| Анимация закрытия | Стандарт niri |
| Длительность | 600 мс |
| Соседи ждут | выкл. (только с niri, который знает `hold-layout`) |
| Анимация открытия | Как при закрытии, в обратную сторону |
| Длительность открытия | 450 мс |
| Светящиеся края | вкл. |
| Случайный выбор идёт из этих | Тление, Осколки, Таяние, Сбой сигнала, Кинескоп гаснет, Дождь из кода |

Обе длительности задаются от 150 до 3000 мс.

## IPC

```sh
dms ipc call windowFx kind shatter   # close animation: a kind, random or default
dms ipc call windowFx open mirror    # open animation: mirror, a kind, random or default
dms ipc call windowFx status
```

Эффекты называются `ember`, `dissolve`, `pixel`, `shatter`, `melt`, `glitch`, `crt`, `snow`, `scan`, `code`, `swirl`, `squares` и `blinds`.

Сочетание клавиш в niri, которое бросает кубик для следующих окон:

```kdl
binds {
    Mod+Shift+W { spawn "dms" "ipc" "call" "windowFx" "kind" "random"; }
}
```

## Соседи ждут

Когда окно закрывается, niri сразу убирает его из раскладки. Соседние окна тут же начинают сдвигаться в освободившееся место, а анимация закрытия ещё рисуется поверх них. С коротким затуханием это почти незаметно; с горящим краем или падающими осколками эффект идёт поверх окна, которое въезжает под него, и они смешиваются.

Я написал для niri небольшой патч, который добавляет в `window-close` опцию `hold-layout`. С ней всё, что запускает удаление окна (соседи сдвигаются, вид прокручивается, колонки меняют размер), начинается только после конца анимации закрытия. Патч не входит в niri, и niri из вашего дистрибутива эту опцию не знает. Без niri, собранного с этим патчем, «Соседи ждут» ничего не делает.

Патч для niri 26.04 лежит в ветке [hold-layout-v26.04](https://github.com/satoshoe-dev/niri/tree/hold-layout-v26.04) моего форка niri. Он собирается так же, как сам niri, см. его README.

При запуске плагин проверяет, знает ли установленный niri эту опцию: он даёт `niri validate` прочитать крошечный файл с ней. Если niri её знает, на странице настроек появляется переключатель «Соседи ждут»; если нет, он остаётся скрытым, и плагин никогда не пишет эту опцию, потому что обычный niri отверг бы весь файл.

## Отключение

Если выключить плагин, `windowfx.kdl` остаётся как есть, и последние анимации сохраняются. Чтобы вернуться к анимациям самого niri, сначала поставьте обе анимации на «Стандарт niri» или удалите файл. С `optional=true` отсутствующий файл для niri не проблема.
