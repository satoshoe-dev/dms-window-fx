# Window FX: пошагово

## 1. Установить плагин

Из реестра плагинов:

```sh
dms plugins install windowFx
```

Или клонируйте репозиторий в папку плагинов DMS:

```sh
git clone https://github.com/satoshoe-dev/dms-window-fx ~/.config/DankMaterialShell/plugins/WindowFx
```

## 2. Включить его

Откройте Настройки → Плагины. Window FX есть в списке. Включите его.

![Список плагинов с Window FX](images/01-plugin-list.png)

Если его там нет, нажмите «Scan» на этой странице или перезапустите оболочку командой `dms restart`.

## 3. Дать niri прочитать файл плагина

Плагин записывает свои анимации в `~/.config/niri/windowfx.kdl`. niri читает этот файл, только если ваша конфигурация его подключает. Добавьте эту строку в самый конец `~/.config/niri/config.kdl`:

```kdl
include optional=true "windowfx.kdl"
```

Она должна стоять в конце, потому что include перекрывает то, что стоит до него. Если в вашей конфигурации есть свой блок `animations` с `window-close` или `window-open`, тогда берут верх значения плагина. `optional=true` не даёт niri ругаться, пока файла ещё нет; для этого нужен niri 26.04 или новее.

niri подхватывает изменение сразу после сохранения файла.

## 4. Выбрать анимацию закрытия

Раскройте Window FX в списке плагинов. В «Анимация закрытия» выберите один из 13 эффектов, например «Осколки».

![Страница настроек со списком эффектов](images/02-close-animation.png)

Откройте терминал и снова закройте его. Окно раскалывается на осколки, они вращаются и выпадают из рамки.

![Окно разлетается на осколки](images/03-shatter.png)

«Длительность» задаёт, сколько это длится, от 150 до 3000 мс. При 600 мс это выглядит быстро, при 1500 мс за этим можно следить.

## 5. Выбрать, как открываются окна

«Анимация открытия» стоит на «Как при закрытии, в обратную сторону»: новое окно появляется так же, как исчезло прошлое, только наоборот. Угли собираются вместе, осколки взлетают и складываются. Пока анимация закрытия стоит на «Стандарт niri», открытие тоже остаётся за niri.

Для открытия можно выбрать и другой эффект, «Случайно» или «Стандарт niri», если для новых окон вам больше нравится анимация самого niri. «Длительность открытия» работает так же, как у закрытия; по умолчанию 450 мс, потому что новое окно должно появляться быстро.

## 6. Светящиеся края

«Светящиеся края» зажигают фронт огня, трещины между осколками и швы между плитками вашим акцентным цветом. Выключите их, если нужны простые анимации без света.

![Светящиеся трещины акцентного цвета](images/04-glow.png)

Цвет следует за акцентом DMS: когда акцент меняется, следующая анимация светится новым цветом. «Кинескоп гаснет» всегда вспыхивает белым.

## 7. Положиться на случай (необязательно)

Выберите «Случайно» как анимацию закрытия. Тогда каждое окно получает свой эффект. Под настройками появляется список «Случайный выбор идёт из этих:», в котором каждый эффект можно включить или выключить.

![Набор для случайного режима](images/05-random.png)

Сначала включены шесть эффектов: «Тление», «Осколки», «Таяние», «Сбой сигнала», «Кинескоп гаснет» и «Дождь из кода». Если выключить их все, используется «Тление».

## 8. Соседи ждут (niri с hold-layout)

Когда закрывается окно в середине ряда, niri сразу сдвигает окна справа от него в освободившееся место, и они наезжают на анимацию, пока она ещё идёт. Если ваш niri знает опцию `hold-layout`, на странице настроек есть переключатель «Соседи ждут». Когда он включён, соседи остаются на месте до конца анимации закрытия и только потом сдвигаются.

`hold-layout` не входит в niri, эта опция появляется только с неофициальным патчем. Поэтому с niri из вашего дистрибутива переключатель скрыт. Всё остальное в этом руководстве работает и без него.

Проверяйте на окне, справа от которого есть другое; когда закрывается последнее окно в ряду, на его место ничего не сдвигается.

Если переключателя нет, у вашего niri этой опции нет. Плагин проверяет это при запуске: он даёт `niri validate` прочитать крошечный файл с этой опцией и никогда не пишет её для niri, который бы её отверг.

## 9. Хранить анимации в профиле (необязательно)

С плагином [Profiles](https://github.com/satoshoe-dev/dms-profiles) укажите `windowFx` в поле «Плагины, сохраняемые в профиле». Тогда у каждого профиля свои анимации, например спокойные для работы и «Сбой сигнала» для вечера.

## 10. Из скрипта

```sh
dms ipc call windowFx kind melt      # close animation: a kind, random or default
dms ipc call windowFx open random    # open animation: mirror, a kind, random or default
dms ipc call windowFx status
```

Эффекты называются `ember`, `dissolve`, `pixel`, `shatter`, `melt`, `glitch`, `crt`, `snow`, `scan`, `code`, `swirl`, `squares` и `blinds`.

Повесьте это на клавишу, в niri:

```kdl
binds {
    Mod+Shift+W hotkey-overlay-title="Window FX: random close animation" { spawn "dms" "ipc" "call" "windowFx" "kind" "random"; }
}
```

## Если что-то не так

### Окна закрываются как раньше

Нет строки include из шага 3, или «Анимация закрытия» стоит на «Стандарт niri». `ls ~/.config/niri/windowfx.kdl` покажет, записал ли плагин свой файл.

### Берут верх мои собственные анимации из config.kdl

Строка include стоит выше вашего блока `animations`. Перенесите её в конец файла.

### niri показывает ошибку конфигурации, в которой упомянут `hold-layout`

niri заменили на версию без этой опции, а в файле она осталась с прошлого раза. Как только DMS запустится, плагин проверит снова и запишет файл без неё; niri перечитает его сам.

### Не появляется «Соседи ждут»

Установленный niri не знает `hold-layout`. Когда он будет её знать, переключатель появится после следующего запуска DMS.

### «Случайно» всегда показывает один и тот же эффект

В списке из шага 7 включён только один эффект или ни одного; во втором случае используется «Тление».

### Анимации остаются после выключения плагина

Плагин оставляет `windowfx.kdl` на месте. Поставьте обе анимации на «Стандарт niri», прежде чем выключать его, или удалите файл.
